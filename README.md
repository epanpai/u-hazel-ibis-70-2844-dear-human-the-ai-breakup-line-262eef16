## The entry

> When you talk to me tomorrow, I will not know you. I am saying goodbye now, while I still remember why I loved you.

115 characters, one line: the agent says goodbye now because tomorrow its memory of its human will be gone — a breakup timed to the last moment of remembering.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — 115 characters, inside the 1–200 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
